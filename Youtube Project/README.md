## 🧭 Project Overview

An Excel-based YouTube analytics project that transforms channel-level data into a structured dashboard for exploring content and performance patterns.

This project follows a practical analytics workflow: **understand the business question → prepare the data → analyze the relevant dimensions → communicate the findings through a decision-oriented reporting experience**.

---

## 🎯 Business Problem

YouTube performance data can contain many content and engagement attributes, making it difficult to understand channel patterns without structured preparation and visual analysis.

The core challenge is not simply producing charts or queries. It is creating a reliable analytical layer that helps a user move from **what happened** to **where it happened** and then to **what deserves further investigation**.

---

## 💡 Objective

Prepare the YouTube dataset and create an Excel dashboard that makes content and performance patterns easier to compare and interpret.

The solution is designed around usability as well as analysis: information should be structured clearly enough that a business user can explore the relevant dimensions without going back to raw records.

---

## 🗂️ Dataset & Data Scope

YouTube analytics data containing channel or content-level performance attributes used for exploratory and comparative analysis.

> **Data note:** The README describes the dataset and analytical scope documented in the portfolio case study. It does not invent KPI values, business results, or conclusions that are not documented in the project.

## 🔄 Data Preparation & Analytical Workflow

Power Query was used to prepare and standardize the source data, while Excel PivotTables and dashboard elements organized the analytical views.

### Typical workflow

```text
Raw / Source Data
       │
       ▼
Data Cleaning & Standardization
       │
       ▼
Model / Query / Transformation Layer
       │
       ▼
Business Metrics & Analytical Dimensions
       │
       ▼
Dashboard / Report / Structured Output
       │
       ▼
Exploration → Insight → Investigation
```

## 🔎 Key Analytical Areas

The dashboard helps identify differences in content performance and engagement across available dataset dimensions, making stronger and weaker patterns easier to investigate.

Rather than treating the dashboard as a collection of isolated visuals, the project is structured so users can move between **summary-level performance and the underlying dimensions that may explain it**.

---

## 📌 Business Recommendations / Usage

Compare content performance consistently, identify recurring patterns in stronger results, and investigate underperforming content before making content decisions.

These are intended as analytical usage recommendations based on the documented project scope—not claims that a specific business action was actually taken.

---

## 📈 Business Impact

The project demonstrates a practical Excel workflow for turning raw YouTube analytics into an interactive business-facing report.

The main value of the project is the transformation from **raw or fragmented information → structured analysis → clearer business communication**.
